# Phase 2 Plan 01: Personal Progress Experience

## Objective

Make Profile a private, useful home for a user’s anonymous identity, reflection activity, and saved reports on Android.

## Tasks

### Task 1: Harden profile data states

1. Load persona and activity together with a visible loading state.
2. Give the user a retry action when activity retrieval fails.
3. Keep the email address out of every displayed profile state.

### Task 2: Complete calendar and report history surface

1. Retain the GitHub-style 90-day activity calendar with accessible day descriptions.
2. Show selected-day context plus recent saved reflection reports.
3. Make empty states explain when activity will appear.

### Task 3: Verify mobile navigation treatment

1. Preserve the root tab safe-area sizing already added for Android system navigation.
2. Run lint and TypeScript verification.

## Acceptance Criteria

- Profile is reachable from Home and uses only a generated or self-chosen alias.
- A signed-in user can see calendar activity, recent reports, and an actionable retry state.
- The mobile build passes lint and type checking.
